# PixelPort — сторінка каталогу ігор (PS5)

Статичний сайт без збірки: HTML + CSS + чистий JavaScript.

## Як запустити
Відкрийте `index.html` у браузері (подвійним кліком) або підніміть локальний сервер:

```bash
cd game-shop
python3 -m http.server 8000   # → http://localhost:8000
```

## Структура
```
game-shop/
├── index.html        — розмітка сторінки (шапка, фільтри, сітка, кошик, футер)
├── css/style.css     — усі стилі, світла/темна тема, адаптив
└── js/
    ├── products.js   — дані товарів (замініть на свої)
    └── app.js        — фільтри, сортування, пошук, кошик, обране
```

## Що вміє
- Пошук, швидкі фільтри (новинки / знижки / передзамовлення / вживані)
- Фільтри: ціна, наявність, стан, жанр (з лічильниками), мова, вік
- Сортування, «Показати ще», активні фільтри-теги
- Кошик (бокова панель) і обране — зберігаються в localStorage
- Адаптив: на мобільному фільтри відкриваються шторкою; темна тема за системними налаштуваннями

## Як додати свої товари
Відредагуйте `js/products.js`. Щоб показати справжню обкладинку, додайте поле
`image: "img/назва.jpg"` (співвідношення 3:4) — інакше малюється кольорова заглушка.
Назву магазину, телефон, адресу і тексти змініть у `index.html`.
